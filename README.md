
設定
| 設定名                 | 意味                  | 数値を上げると                              | 数値を下げると                       |
| ------------------- | ------------------- | ------------------------------------ | ----------------------------- |
| **paint qty.**      | 一回の調色で出る**絵の具の総量**  | 出る量が増える。色の比率は同じまま、**全体が濃くなる / 多く出る** | 出る量が減る。**薄くなる / 少量になる**       |
| **black weight**    | 黒絵の具を**どれくらい強く使うか** | **黒が強くなる**。全体が暗め・締まった色になる            | **黒が弱くなる**。CMYや水寄りになり、明るめになる  |
| **gamma black**     | 黒が効き始める**カーブの形**    | 黒が出るのが**遅くなる**。かなり暗くなるまで黒が増えない       | 黒が**早く効き始める**。少し暗くしただけでも黒が増える |
| **gamma color**     | CMY（カラー）の**強さカーブ**  | 弱い色はさらに弱くなり、**強い色だけが強く出る**（メリハリが強い）  | 弱い色でも出やすくなり、**全体的に色が出やすい**    |
| **threshold black** | **黒を使い始める境界**       | 黒を使うのが**遅くなる**（かなり暗くならないと黒を使わない）     | 黒を**早く使い始める**                 |
| **step delay**      | ポンプの**動作スピード**      | 動作が**遅くなる**（安定しやすいが時間がかかる）           | 動作が**速くなる**（ただし速すぎると脱調する可能性）  |
